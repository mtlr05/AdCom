# FDA advisory committee pivotal votes vs FDA decisions (2016-11-04 to 2026)

One row per adcom meeting x product where the committee voted on approval (or the closest effectiveness question) of a specific NDA/BLA, with the FDA's later decision, orphan status for the indication, review priority, center, CGT flag and vote type. Built as a prior for adcom outcome probabilities (e.g. uniQure AMT-130).

## Quick start
```bash
pip install -r requirements.txt     # Python 3.11+ (tested on 3.13)
./run_all.sh                        # offline; ~1 min; ends with "run_all.sh: OK"
```
`run_all.sh` runs `cur.py -> final.py -> report.py -> four.py / four_pct.py / four_cgt.py / cgt_tables.py -> tests/check_consistency.py`, using `data/` as working directory and writing charts to `charts/`.

## Layout
| Path | What |
|---|---|
| `data/adcom_full_pivotal.csv`, `data/adcom_full.xlsx` | Main table (155 rows). See DATA_DICTIONARY.md |
| `data/two_by_two.csv` | 2x2 counts by subset (all votes and approval-only) |
| `data/excluded.csv`, `data/gaps.csv` | Meetings seen but excluded (with reason); open gaps (0) |
| `data/coverage_vs_daval.csv`, `data/daval_*.csv` | Completeness vs Daval et al. 2023 |
| `data/orphan_audit_2026-11-04.csv` | Orphan label audit log (old, new, basis, source) |
| `data/curated.csv`, `data/field_overrides.csv` | Generated by `scripts/cur.py`; the only place corrections live |
| `data/inputs/` | Upstream hand-verified inputs (legacy PCNS/CTGTAC workbook, CGT check) |
| `data/meetings.pkl`, `gaps.pkl`, `excluded.pkl` | Output of the (slow, online) crawl/parse stage, consumed by `final.py` |
| `data/ofda/`, `data/oopd_all.csv`, `data/cache/` | openFDA, OOPD and minutes-text caches. See `data/MANIFEST.csv`, `data/cache/large_cache_manifest.csv` |
| `scripts/` | Pipeline scripts; `scripts/crawl/` = crawl/parse stage (online, not run by run_all.sh) |
| `charts/` | Final charts (`*_v4` all votes, `*_approvalonly_v5`) and CGT PDFs |
| `REPORT.md` (in data/) | Generated report |

Read AGENTS.md before changing anything; SPEC.md defines the acceptance test; LIMITATIONS.md lists what is not verified.
