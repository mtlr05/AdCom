# Natural-history page

Read `natural-history/README.md` and apply the class written there.

Do not widen it to any external control, a literature rate, a chart review, another trial’s arm, or a patient’s own baseline.

A search for new rows starts from the FDA approval and complete-response lists after October 2022 and adds a line to `natural-history/screen_log.csv`, not from names already on the page.

Edit only `natural-history/index.html`. Cite an FDA letter, review, label, or snapshot for every number.

The class is written in `natural-history/README.md`. Do not restate it.
